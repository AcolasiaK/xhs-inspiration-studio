# 本机使用指南

## 选择启动方式

首次进入下载的项目目录，执行 `npm ci` 安装锁定的依赖。新用户可以先选开发方式试用。

| 使用方式 | 操作 | 打开方式 |
| --- | --- | --- |
| 开发和第一次试用 | `npm run dev` | 浏览器打开 `http://127.0.0.1:3000`，保持终端开启 |
| macOS 日常使用 | 先停掉自己启动的开发服务，再执行 `npm run local:install` | 双击根目录的「启动小红书工作台.command」。它会启动当前账号的服务并打开个人创作页 |
| 本机生产构建预览 | `npm run build` 后执行 `npm run start` | 浏览器打开相同地址。保持终端开启 |

稳定版用 macOS LaunchAgent 管理。用 `npm run local:status` 查看状态，`npm run local:stop` 停止，`npm run local:start` 恢复。更新源码后先运行 `npm ci`，保存草稿并等当前生成结束，再运行 `npm run local:update`。首次安装需要本机已有 Node.js 和 npm。

3000 端口已有其他服务时，开发预览可用 `npm run dev -- --port 3100`，再打开 `http://127.0.0.1:3100`。不同端口对应不同的浏览器存储空间。桌面启动器使用固定的 3000 端口。

## 配置一个自己的模型

1. 进入左下角「AI 配置」，新增配置。官方服务可直接选服务类型，兼容服务按供应商文档填写基础地址和协议。
2. 填入对应服务商的 API Key，点击「获取模型列表」，或手动填写模型 ID。保存后按需要设为默认。
3. 点击「测试文字」。计划上传照片时再点「测试图片理解」。两个测试分别验证相应能力，可能产生少量 API 用量。
4. 回到创作页，选择已保存的配置，并将生成方式切换为「真实生成」。模板中的主题、经历、图片会作为对应任务的输入发送给该服务。

首次体验固定演示、浏览页面和本地编辑都可以跳过这一步。网页中的 AI 配置适用于日常使用。仓库根目录另附 [.env.example](../.env.example) 供了解旧式环境变量接入；需要使用时仅在自己电脑上的 `.env.local` 填值。

## 使用浏览器检索

本机热点采集依赖 OpenClaw 网关和专用浏览器。当前实现从 `~/.openclaw/bin/openclaw` 调用 CLI，并使用名为 `openclaw` 的浏览器配置。先确认对应路径可执行并已启动网关，再执行以下命令检查浏览器。[OpenClaw 浏览器文档](https://docs.openclaw.ai/tools/browser)

```bash
~/.openclaw/bin/openclaw browser --browser-profile openclaw status
```

需要小红书登录时，请在该配置的浏览器里自行登录，再回到「今日热点」手动更新一个分类。网页可访问范围、登录状态和公开来源数量都会影响当次结果。资料不足时以页面显示的证据为准。固定图文演示可以独立使用。

## 常见问题

| 现象 | 可以怎么处理 |
| --- | --- |
| 双击启动文件提示尚未安装 | 首次先在项目目录执行 `npm ci` 和 `npm run local:install` |
| 运行时找不到本地 `lodash.set` | 确认下载了整个仓库，`vendor/lodash-set-safe` 与 `package-lock.json` 都在项目内，再执行 `npm ci` |
| 模型列表能加载，生成仍失败 | 检查所选协议、模型权限、额度及文字或图片能力测试结果，按页面的错误提示处理 |
| 切换地址后草稿箱看起来是空的 | 使用之前相同的浏览器、网址和端口。清除站点数据会一并清除该站点的本地草稿，重要文案可先导出 |
| 热点更新提示连接浏览器失败 | 检查 OpenClaw 网关、CLI 路径、浏览器配置及登录状态，手动完成页面要求的验证后再重试 |

本机启动命令把服务绑定到回环地址。代码也包含独立的 CloudBase 模式，需要自行配置身份验证、私有资源和环境变量。[云端模式说明](../DEPLOY_CLOUDBASE.md)
